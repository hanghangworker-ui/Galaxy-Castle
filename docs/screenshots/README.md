## 新增截图

1. 游戏内截屏（先按 `F11` 全屏），保持 16:9。
2. 存成 PNG，小写连字符 + 两位数字前缀：`34-example.png`。
3. 控制在 ~600 KB 以内——过大就用 [Squoosh](https://squoosh.app/) 或 `pngquant --quality=65-85` 压一下。
4. 在本文件加一行，并在 `README.md`（截图表格）或 `README.zh-CN.md` 里引用它。
