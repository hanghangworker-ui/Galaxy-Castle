## Adding a screenshot

1. Take the capture in game (`F11` for fullscreen first), keep it 16:9.
2. Save it as PNG, lowercase with hyphens and a two-digit prefix: `09-broken-rampart.png`.
3. Keep it under ~600 KB — run it through [Squoosh](https://squoosh.app/) or `pngquant --quality=65-85` if needed.
4. Reference it from `README.md` (the screenshot table) or `README.zh-CN.md`.
